# FJKT48

FJKT48 is an unofficial fan-made community portal dedicated to [JKT48](https://jkt48.com/), built with cutting-edge web technologies for high performance, accessibility, and an interactive fan experience.

## Getting Started

To start developing locally:

```bash
bun install
bun dev
```

## Technologies Used

| ------------------- | ------------------------------------------------------------------------------------- |
